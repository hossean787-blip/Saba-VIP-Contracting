# پیمانکاری صبا VIP | Saba VIP Contracting

اپ آفلاین و مستقل مدیریت پیمانکاری با Flutter و SQLite برای مدیر شرکت.

## قابلیت‌های آزمایشی نسخه 0.2.0
- مدیریت شرکت، قراردادها، عملیات و مراحل پروژه
- ثبت هزینه، پرداخت، دریافت و صورت‌وضعیت
- گزارش‌های مالی و نمودارهای تفکیکی هر قرارداد
- خروجی PDF و Excel و پشتیبانی از تاریخ شمسی
- پردازش و ذخیره‌سازی محلی بدون سرور

## ساخت روی GitHub Actions
پس از انتقال سورس، گردش‌کار **Android v0.2 validation** آزمون‌های Flutter را اجرا و APK آزمایشی تولید می‌کند؛ موفقیت واقعی فقط پس از اجرای گردش‌کار و بررسی خروجی قابل تأیید است.

> ⚠️ **نسخه آلفا، نه محصول آماده استفاده واقعی.** پشتیبان‌گیری رمزگذاری‌شده، بازیابی و آزمون روی گوشی تکمیل نشده‌اند. از ثبت داده‌های حقیقی شرکت خودداری کنید؛ امضای APK آزمایشی پایدار و تجاری نیست.

## راه‌اندازی محلی
پس از نصب Flutter و Android SDK:
```bash
bash tool/bootstrap_android.sh
flutter analyze
flutter test
flutter build apk --release
```

مخزن عمومی است، اما تا تعیین LICENSE هیچ مجوز بازتوزیع یا استفاده تجاری صریحی اعطا نشده است.
