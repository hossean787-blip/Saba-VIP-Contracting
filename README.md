# پیمانکاری صبا VIP | Saba VIP Contracting

اپ مستقل و آفلاین مدیریت پیمانکاری با Flutter و SQLite.

## قابلیت‌های نسخه آزمایشی ۰.۳
- ثبت اطلاعات شرکت، قراردادها، هزینه، پرداخت، دریافت و صورت‌وضعیت
- گزارش، نمودار و خروجی PDF / Excel
- تب عملیات: نمایش فعالیت‌های همه قراردادهای شرکت، فیلتر وضعیت و اصلاح درصد پیشرفت
- پشتیبان رمزگذاری‌شده SQLite با AES-256-GCM و بازیابی با رمز و تأیید صریح؛ حفظ کپی بازگشت اضطراری
- شناسه برنامه و گواهی امضای پایدار، شماره ساخت افزایشی برای نصب آپدیت بدون حذف نسخه قبلی

## ساخت اندروید در GitHub
Workflow: **Android Release (permanent signature + backup v0.3)**

Workflow پس از اجرای آزمون‌های Flutter و Python، نسخه Release را با امضای دائمی و شماره ساخت بزرگ‌تر می‌سازد و امضا و شناسه را کنترل می‌کند. Secretهای کلید نباید وارد مخزن عمومی شوند.

## محدودیت‌های مهم
- نسخه آزمایشی است؛ روی گوشی واقعی بازیابی و نصب آپدیت باید با داده نمونه تأیید شود.
- پشتیبان فعلاً تنها SQLite را ذخیره می‌کند و پیوست‌های خارجی هنوز پشتیبانی نمی‌شوند.
- فراموش‌شدن رمز پشتیبان به معنی از دست‌رفتن امکان بازیابی است.
- اطلاعات واقعی و غیرقابل‌بازیابی را تا پایان آزمون میدانی وارد نکنید.
