## فعال‌سازی یک‌باره
۱. بسته خصوصی Saba_VIP_Permanent_Signing_Setup_PRIVATE.zip را از گفت‌وگوی شخصی دانلود کنید.
۲. فایل GITHUB_SECRETS_PRIVATE.txt شامل دو مقدار است: SABA_RELEASE_KEYSTORE_B64 و SABA_RELEASE_STORE_PASSWORD.
۳. در GitHub > Settings > Secrets and variables > Actions > New repository secret هر دو مورد را جداگانه با نام دقیق ایجاد کنید. در قسمت Value فقط عبارت بعد از علامت مساوی را قرار دهید.
۴. فایل p12 و رمز آن را در دو جای خصوصی و مستقل از GitHub نگهداری کنید. هرگز فایل کلید یا رمز را در مخزن عمومی آپلود نکنید.
۵. پس از آن Actions > Android Release (permanent signature) > Run workflow را اجرا کنید.

## قوانین نصب نسخه‌های بعدی
- شماره برنامه (applicationId)، کلید امضا و داده‌های اپ باید یکسان بمانند.
- شماره build هر نسخه جدید = 10000 + GITHUB_RUN_NUMBER است و در اجرای متوالی همین Workflow افزایش می‌یابد.
- نسخه قبلی 0.2.0 با گواهی Debug موقت امضا شده بود؛ بدون کلید خصوصی قبلی نمی‌توان آن را بدون حذف، به کلید جدید منتقل کرد.
- پیش از هر حذف احتمالی از داده‌ها نسخه پشتیبان امن بگیرید. اگر بکاپ در دسترس نیست، اپ قدیمی را حذف نکنید.
- از نخستین APK امضاشده با کلید دائمی به بعد، نسخه‌های دارای همان گواهی، همان شناسه و versionCode بالاتر باید به‌شکل آپدیت نصب شوند.
- نبود یا اشتباه‌بودن Secrets باید ساخت Release را متوقف کند، نه اینکه APK با امضای Debug تولید شود.

نسخه فعلی برای اطلاعات واقعی شرکت تأیید نشده است؛ سیستم پشتیبان‌گیری و آزمون واقعی ارتقا هنوز باقی‌اند.
