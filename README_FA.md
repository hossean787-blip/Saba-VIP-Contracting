# پیمانکاری صبا VIP — نسخه ۰.۲ آزمایشی

## وضعیت صادقانه
این بسته یک **پروژه Flutter با سورس واقعی** است، نه APK آماده نصب. هسته SQLite و فرم‌های نسخه ۰.۱ حفظ شده و ماژول گزارش، نمودار و خروجی PDF و XLSX به آن اضافه شده است. روی سیستم تولید این بسته Flutter SDK/Android SDK وجود نداشت، بنابراین کد Dart، خروجی PDF واقعی در Flutter، ویجت‌ها و APK هنوز **کامپایل یا روی گوشی اجرا نشده‌اند**.

## امکانات قابل مشاهده در کد
- مدیریت شرکت، قراردادها، عملیات، هزینه، پرداخت، دریافت و صورت‌وضعیت‌ها (نسخه ۰.۱).
- منوی سوم **گزارش‌ها** در نوار پایین و دکمه «نمودار و گزارش» در پرونده قرارداد.
- گزارش اختصاصی هر قرارداد، فیلتر «همه/هزینه/پرداخت/دریافت/صورت‌وضعیت/عملیات».
- نمودار مقایسه‌ای هزینه، پرداخت، دریافت، کار تأییدشده؛ نمودار ماهانه دریافت/پرداخت و دسته‌بندی هزینه‌ها.
- فایل واقعی Excel با دو شیت راست‌به‌چپ («خلاصه» و «ریز عملیات») و اعداد واقعی نوع عددی، نه تصویر یا CSV با پسوند جعلی.
- فایل PDF چندصفحه‌ای فارسی با فونت دارای مجوز OFL که **در زمان ساخت** در APK قرار می‌گیرد. تولید گزارش روی دستگاه آفلاین است.
- اشتراک‌گذاری فایل PDF/XLSX از طریق Share Sheet سیستم عامل؛ ذخیره نهایی بستگی به برنامه‌ای دارد که مدیر انتخاب می‌کند.
- تصویر `preview/reports_concept.html` صرفاً یک پیش‌نمایش بصری است؛ رندر Flutter نیست و ارقام آن فرضی هستند.

## معنی شاخص‌های مالی
«هزینه» و «پرداخت» جدا ثبت می‌شوند؛ «کار تأییدشده» با «دریافت نقدی» یکسان نیست. `approved gross - costs` مازاد **اولیه و غیرقطعی** است. `receipts - payments` جریان نقدی است، نه سود. در نسخه فعلی کسورات صورت‌وضعیت از شاخص «مازاد اولیه» کسر نشده و این شاخص نباید برای گزارش رسمی استفاده شود.

## ساخت آزمایشی Android
1. بر روی Linux یا macOS با Flutter stable و Android SDK نصب‌شده (JDK 17):

```bash
bash tool/bootstrap_android.sh
flutter analyze
flutter test
flutter build apk --release
```

2. اسکریپت `tool/prepare_fonts.sh` فونت فارسی آزاد Noto Naskh Arabic (OFL) را فقط برای ساخت دانلود می‌کند. پس از ساخت، **تولید PDF روی گوشی هیچ اینترنتی نمی‌خواهد**. فونت در فایل سورس ZIP توزیع نمی‌شود. URL رسمی فونت و مجوز در `docs/DEPENDENCIES_FA.md` توضیح داده شده است.
3. برای ساخت بدون SDK محلی، سورس را در یک **مخزن مستقل** GitHub بارگذاری کرده و Workflow `Android v0.2 validation (offline reports)` را اجرا کنید. این Workflow فونت و Android scaffold را تهیه می‌کند و تحلیل کد، آزمون‌ها و ساخت را انجام می‌دهد.
4. **توجه:** APK حاصل از Android scaffold موقت با کلید پیش‌فرض آزمایشی امضا می‌شود؛ برای ارتقا و نصب تولیدی باید keystore پایدارِ خصوصی تعریف شود. این نسخه را تجاری یا آماده ورود داده واقعی تلقی نکنید.

## آزمون در محیط تولید بسته

```bash
python3 -m unittest discover -s tests_python -p 'test_*.py' -v
python3 tool/check_dart_delimiters.py
```

۳۸ تست SQL/Python موفق شدند. بررسی موازنه علائم کد Dart نیز گذشت؛ **این بررسی جایگزین کامپایل و `flutter analyze` نیست**. آزمون‌های `test/report_model_test.dart` و `test/report_exports_test.dart` نوشته شده ولی هنوز اجرا نشده‌اند.

## محدودیت‌های حیاتی قبل از استفاده واقعی
- پشتیبان‌گیری رمزگذاری‌شده / بازیابی هنوز پیاده نشده: حذف برنامه ممکن است داده‌ها را از بین ببرد.
- قفل بیومتریک، لوگو، اعلان محلی، مدیریت پوشه فایل‌های ضمیمه، اصلاح/ابطال تراکنش‌ها و ثبت تسویه جزئی هنوز تکمیل نشده‌اند.
- صحت PDF فارسی و بازشدن XLSX در Excel واقعی باید روی APK ساخته‌شده آزمون شود.
- هیچ سرور، حساب ابری، اشتراک دوره‌ای یا پرداخت اجباری برای امکانات اصلی تعریف نشده است.
- پروژه مستقل از دیگر پروژه‌های صبا است؛ هیچ مخزن دیگری تغییر داده نشده.
