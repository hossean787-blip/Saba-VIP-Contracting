# پیمانکاری صبا VIP — نامزد نسخه تجاری ۱.۰.۰-rc.1

برنامه **Flutter/Android** مستقل، فارسی و راست‌به‌چپ با ذخیره‌سازی آفلاین SQLite برای امور پیمانکاری. این نسخه یک **نامزد انتشار برای آزمون نهایی** است و تا گذر از دروازه دستگاه واقعی، امنیت داده و ملزومات حقوقی، نباید به‌عنوان نسخه تجاری نهایی فروخته شود.

## امکانات پیاده‌سازی‌شده
- ایجاد/ویرایش مشخصات شرکت، قراردادها و عملیات اجرایی.
- شناسایی مستقل هزینه از پرداخت: بدون انتخاب پرداخت = بدهی پرداخت‌نشده؛ تسویه کامل یا جزئی با جلوگیری از بیش‌پرداخت و نمایش مانده.
- دسته‌بندی هزینه‌ها و دریافت‌ها، صورت‌وضعیت‌ها و مرکز مطالبات با تطبیق وجوه و ردیابی تغییرات.
- ردیف‌های متره و برآورد، ثبت برگ متره افزایشی/کاهشی مستند، صدور پیش‌نویس صورت‌وضعیت و جلوگیری از دوباره‌صورتحساب‌شدن.
- ورود دسته‌ای فهرست‌بها با قالب XLSX، پیش‌نمایش، بررسی تکراری‌ها و ثبت یکپارچه در قرارداد مربوط.
- گزارش‌های قرارداد، PDF فارسی، XLSX قابل محاسبه و نمودارهای آفلاین.
- پشتیبان خروجی رمزگذاری‌شده AES-256-GCM، بازیابی با حفظ نسخه اضطراری، بررسی سلامت فایل بدون جایگزینی داده‌ها.
- قفل اختیاری رابط با اثرانگشت/چهره/رمز دستگاه و پوشش رابط هنگام پس‌زمینه.
- محدودکردن بکاپ خودکار بدون رمز در AndroidManifest و قطع ارتباط HTTP بدون TLS.
- صفحه «درباره برنامه و حریم خصوصی» همراه افشای محدودیت‌ها.

## راهنمای کار
۱. شرکت را ایجاد کنید. ۲. قرارداد فعال را انتخاب کنید. ۳. هزینه‌ها و پرداخت‌های مستقل یا جزئی را ثبت کنید. ۴. برای هر قرارداد ردیف‌های فهرست‌بها و برگ متره را وارد کنید. ۵. پیش‌نویس صورت‌وضعیت را با مدارک تأیید کنید. ۶. دریافت‌ها را در مرکز مطالبات تطبیق دهید. ۷. گزارش PDF/XLSX بگیرید. ۸. پشتیبان رمزگذاری‌شده را خارج از گوشی نگه دارید.

## نصب و ساخت اندروید
شناسه بسته: \`ir.saba.vip.saba_vip_contracting\`. نسخه‌های امضاشده پایدار فقط با همین گواهی و شماره ساخت افزایشی روی یکدیگر نصب می‌شوند.

\`\`\`bash
bash tool/bootstrap_android.sh
flutter analyze
flutter test
python3 -m unittest discover -s tests_python -p 'test_*.py'
flutter build apk --release
\`\`\`

ساخت Release در GitHub Actions با کلید خصوصی ذخیره‌شده در Secrets انجام می‌شود. هرگز امضای موقت یا Debug را به‌جای نسخه نهایی عرضه نکنید.

## شواهد آزمون نامزد انتشار
- ۹/۹ دروازه کیفیت آفلاین موفق.
- ۱۱۸/۱۱۸ آزمون Python/SQLite موفق.
- \`flutter analyze\` و \`flutter test\` در PR CI موفق.
- آزمون واقعی اجرای برنامه، ایجاد شرکت و صفحات حریم خصوصی و پشتیبان‌گیری روی **شبیه‌ساز Android API 35** موفق (GitHub Actions شماره 43000299244).
- ساخت APK Release و کنترل امضای همین نامزد نسخه پس از ادغام در main انجام می‌شود. **شبیه‌ساز معادل آزمون گوشی واقعی نیست.**

## محدودیت‌های مهم
- پایگاه داده SQLite داخل برنامه **رمزگذاری در حالت سکون ندارد**؛ قفل اختیاری رابط جایگزین رمزگذاری بانک نیست.
- داده‌ها محلی هستند؛ همگام‌سازی چند دستگاه/سرور تجاری وجود ندارد.
- موتور کامل تعدیل قانونی، کسورات تفصیلی همه پیمان‌ها و پیمانکاران جزء هنوز کامل نیستند.
- آزمون واقعی نصب/ارتقا از ۰.۹.۱، بازیابی و سلامت داده‌ها روی گوشی و مستندات حقوقی/پشتیبانی ناشر برای فروش لازم‌اند.
- نرخ‌های مالیاتی و ضرایب قانونی خودکار یا بدون سند پیمان فرض نمی‌شوند.
